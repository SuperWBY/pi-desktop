# Chrome Web Store listing — Pi Desktop Chrome Bridge

## Name

Pi Desktop Chrome Bridge

## Short description (132 chars max)

Connect the active Chrome tab to Pi Desktop's local browser automation.

## Detailed description

Pi Desktop Chrome Bridge is the optional Chrome companion for the Pi Desktop
desktop app. It lets Pi Desktop observe and operate the **active Chrome tab**
through a local authenticated bridge on 127.0.0.1. It is intended for users who
want to reuse their existing Chrome login session instead of a separate
automation browser profile.

The extension has one purpose: connect Pi Desktop to the active tab. It does
not run as a general-purpose remote-control service, does not install a native
messaging host, and does not enable Chrome remote debugging.

### How it works

1. Pi Desktop prepares a paired copy of this extension.
2. The user loads that copy in Chrome and keeps Pi Desktop running.
3. When the user starts a browser task, Pi Desktop asks the extension for the
   active tab's interactive elements.
4. Pi Desktop sends an approved action back through the local bridge.

### Safety

- Password and payment values are masked. Sensitive input requires an explicitly user-provided value or approval for that operation; otherwise Pi Desktop stops for handoff. Existing login and CAPTCHA handoffs remain in place.
- `chrome://` and extension pages are rejected.
- The bridge is bound to 127.0.0.1 and authenticated with a per-user key.
- The extension operates only on the active tab.
- Page content is treated as untrusted input.
- Pi Desktop asks for approval according to the user's configured tool policy.

### Requirements

- Pi Desktop for macOS (the Chrome bridge is optional; the in-app browser and
  dedicated CDP Chrome modes do not require it).
- Google Chrome 120 or newer.
- The extension must be reloaded after a Pi Desktop update.

## Permission justification

| Permission | Why it is needed |
| --- | --- |
| `activeTab` | Only act after the user starts a task in Pi Desktop for the current tab. |
| `scripting` | Read interactive elements and apply the approved click/type action in the page. |
| `tabs` | Identify the active tab, its URL, and title for the local bridge. |
| `alarms` | Wake the service worker so it can reconnect to the local bridge. |
| `http://127.0.0.1/*` | Talk only to the local Pi Desktop bridge. |
| `<all_urls>` | The user may choose any website for a task; the extension still only operates the active tab. |

## Privacy practices

- Website content: used only to provide the single browser-automation purpose.
- No sale of data.
- No advertising, analytics, or tracking.
- No remote code.
- Privacy policy: link to `docs/chrome-bridge-privacy.md` in the repository.

## Review notes

This extension is useless without the separately distributed Pi Desktop app.
It connects only to a loopback bridge and requires a per-user pairing key
generated by that app. The extension does not collect analytics and does not
send page data to the developer's servers.
